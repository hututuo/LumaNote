# Historical feed experiment

This inert patch preserves an unfinished experiment against the version 0.1.2 test feed. It changes only the publication date and a public Sparkle signature. The original release URL and package size are unchanged.

The patch is a historical fixture, not a verified signature or an active update feed. It has not been applied to the current feed, and no package/signature/startup acceptance has been performed for this experiment. Applying it directly to the current feed is not supported.

This branch starts from the same application source as its base; only this fixture and its explanation are added. It preserves the experiment for later inspection without importing its original commit history.
