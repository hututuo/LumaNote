# Historical source snapshot

This branch restores a previous product source version under app/QuietNote, including its tests, build scripts, resources and dependency manifests. It is retained for recovery and comparison, not as the current release.

Other public repository documents and workflow definitions come from the sanitized baseline and may describe the newer application. Refer to this branch's Package.swift and build scripts when inspecting its historical implementation.

The original raw Git history and internal operational documents are not imported. Build, runtime, signature and installation checks have not been run for this snapshot. Do not treat this branch as a verified update package.
