# LumaNote v0.1.1

Release date: 2026-06-11

## Highlights

- Adds Sparkle-based in-app update checking with a visible menu item and Settings control.
- Keeps the bundle identifier and ad-hoc signing requirement stable as `com.hututuo.lumanote` so macOS permissions can survive updates.
- Adds the Accessibility permission check UI used to confirm permission retention after Sparkle updates.
- Keeps automatic update checks enabled by default with a daily Sparkle schedule.

## Installation

Download the DMG from GitHub Releases, verify the SHA256 checksum, open the DMG, and drag `LumaNote.app` to `Applications`.

This build is ad-hoc signed and is not Apple notarized. macOS may show an "unidentified developer" warning on first launch. Download only from the official release page and verify the SHA256 checksum before opening.

If macOS blocks the first launch, open `System Settings` -> `Privacy & Security`, find the LumaNote warning, click `Open Anyway`, then confirm `Open`.

## Update Path

Sparkle uses the appcast at:

```text
https://raw.githubusercontent.com/hututuo/LumaNote/test/ad-hoc-permission-update/appcast-test/appcast.xml
```

The Sparkle update archive is signed with the committed public EdDSA key in `app/QuietNote/support/Info.plist`. The private key must stay in the release operator's login Keychain under account `com.hututuo.lumanote`, or in a user-private file passed through `SPARKLE_PRIVATE_KEY_FILE`.

## Checksums

Checksums are generated by:

```bash
cd app/QuietNote
LUMANOTE_SKIP_APPCAST=1 ./scripts/prepare-release.sh
cat build/releases/v0.1.1/SHA256SUMS-v0.1.1.txt
```

For a signed appcast build, omit `LUMANOTE_SKIP_APPCAST=1` after the Sparkle private key is available.

## Verification

The release gate should run:

```bash
cd app/QuietNote
swift test
./scripts/build-app.sh
codesign --verify --deep --strict --verbose=2 build/LumaNote.app
codesign -d -r- build/LumaNote.app
./scripts/build-dmg.sh
hdiutil verify build/LumaNote-0.1.1-macos-arm64.dmg
LUMANOTE_SKIP_APPCAST=1 ./scripts/prepare-release.sh
```

Sparkle signature verification additionally requires the private key:

```bash
SPARKLE_PRIVATE_KEY_FILE="$HOME/.config/lumanote/sparkle-ed25519-private.key" \
  ./scripts/prepare-release.sh
```
