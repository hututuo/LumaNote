## Warnings

- The app is ad-hoc signed and not Apple notarized. macOS Gatekeeper can show the unidentified developer flow on first launch.
- The Sparkle private key is not in the repository. Future release operators need access to the same Sparkle key, currently expected under Keychain account `com.hututuo.lumanote` or a user-private `SPARKLE_PRIVATE_KEY_FILE`.

## External Dependencies

End users do not need Homebrew, Node.js, Python, a local server, MCP server, daemon, or sidecar process. The app bundles Sparkle.framework. Source installs require Swift/Xcode Command Line Tools because they build locally.

## Global/System Changes

No global configuration, certificates, Developer ID identities, LaunchAgents, shell files, or system settings were modified. The release flow read the existing Sparkle signing key from the login Keychain account `com.hututuo.lumanote`; no private key was written to the repository or release assets.
