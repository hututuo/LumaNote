# LumaNote v0.1.1 Release Audit

Audit time: 2026-06-11 02:14 CST

## Ready

Partial.

The local build, ad-hoc signature, DMG packaging, checksum generation, appcast metadata syntax, dependency review, and install/launch smoke test passed. Publishing is still gated by source push/tag/release creation and by the Sparkle private-key limitation described below.

## Blockers

- Sparkle appcast signing cannot be regenerated in this non-interactive run because `sign_update --verify --account com.hututuo.lumanote` waited for Keychain access. The release uses the existing appcast-signed `appcast-test/LumaNote-0.1.1-macos-arm64.zip`. To regenerate appcast, unlock/approve the Keychain key or provide `SPARKLE_PRIVATE_KEY_FILE` from a user-private path such as `~/.config/lumanote/sparkle-ed25519-private.key`.
- No GitHub release exists yet at audit time. The appcast now points to `https://github.com/hututuo/LumaNote/releases/download/v0.1.1/LumaNote-0.1.1-macos-arm64.zip`, so Sparkle update delivery requires uploading that exact signed zip to the `v0.1.1` GitHub Release.

## Warnings

- Signing policy is ad-hoc and not notarized. `spctl --assess --type execute -vv build/LumaNote.app` returns `rejected`, which is expected and documented in the README.
- The appcast feed is still hosted on the `test/ad-hoc-permission-update` branch. Move to a stable branch/feed before treating this as a public main-channel release.
- Dependency vulnerability checks for SwiftPM are limited to pinned dependency review and license review. SwiftPM has no built-in vulnerability audit equivalent in this project.

## Passed Checks

- `swift package show-dependencies` reports only `KeyboardShortcuts 1.17.0` and `Sparkle 2.9.3`.
- Dependency licenses checked from SwiftPM checkouts: KeyboardShortcuts is MIT; Sparkle is MIT-style with bundled permissive external notices.
- Secret scan by `rg` found no private Sparkle key, token, password, or API key in tracked source paths reviewed. The public Sparkle EdDSA key is intentionally committed in `Info.plist`.
- Permission surface reviewed: Accessibility, Login Items, local clipboard monitoring. README explains each permission.
- External services reviewed: no server, MCP server, database, daemon, helper install, Homebrew, Node.js, Python, or sidecar dependency is required for DMG/zip users.
- App bundle ad-hoc signing passed with stable designated requirement `identifier "com.hututuo.lumanote"`.
- DMG verification passed and mounted contents include `LumaNote.app`, `Applications` symlink, and `.background`.
- Final release checksums passed with `shasum -a 256 -c SHA256SUMS-v0.1.1.txt`.
- Temporary install/launch smoke from `LumaNote.app.zip` passed with `running_processes=1`.
